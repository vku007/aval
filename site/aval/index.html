Admin hub

Files, users, and games. Same table UI on every manager.

Hub Files Users Games Profile

These pages call /apiv2/internal/* with an admin JWT. A bad or legacy object is a flagged row, not a blank page. This hub stays here after login; it does not send you to the company homepage.

Managers
Area What it manages API
Files JSON objects in S3. Unreadable files stay as rows; delete still works. /apiv2/internal/files
Users Cognito accounts, S3 game profiles, per-user games, audit logs. /apiv2/internal/cognito-users
Games Game list from S3 keys. Legacy move/round JSON is flagged, listing continues. /apiv2/internal/games
Profile Current signed-in user from /apiv2/external/me. /apiv2/external/me
Internal API
Resource Methods
Files GET/POST /files, GET/PUT/PATCH/DELETE /files/{id}, GET /files/{id}/meta
Cognito users GET/POST /cognito-users, GET/PATCH/DELETE /cognito-users/{username}, game-profile, games, GET /audit-logs
Games GET/POST /games, GET/PUT/PATCH/DELETE /games/{id}, rounds, moves, finish
S3 user profiles GET/POST /users, GET/PUT/PATCH/DELETE /users/{id}
